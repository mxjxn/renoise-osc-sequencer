Mappings

A mapping assigns a two-character tracker ID to an OSC destination, address, and value conversion. Mappings are stored in the current .xrns.

Fields

FieldMeaning
ID01 through ZZ. 00 is reserved for an empty effect.
DestinationBlender uses port 57141. Generant uses port 57142.
AddressThe exact OSC address sent by the tool.
Min / MaxOutput range and trigger on/off values.
Fixed argumentsComma-separated strings or numbers inserted before the converted value.
Enum valuesSemicolon-separated strings addressed by the byte value.

Generant device parameter

Use destination generant, address /generant/v1/device/param, and fixed arguments such as keys, cutoff. The converted effect value is appended, producing:

/generant/v1/device/param "keys" "cutoff" 1200
