Renoise tool

Write OSC in the pattern editor.

The tool interprets effect-column commands on [OSC] tracks, sends them during Renoise playback, and exports the arrangement in the JSON format imported by OSC Score Bridge.

Pattern

01 FF

Mapping 01, byte value FF.

Mapping

01 /visual/kick trigger

The mapping supplies the address and behavior.

Output

/visual/kick 1
/visual/kick 0

The release is generated automatically.

Install

  1. Download Generant-Osc-Renoise.xrnx from a release, or clone the repository and run ./scripts/package.sh.
  2. Open the .xrnx file. Renoise copies it into the user tools directory.
  3. Open Tools → Generant OSC → Mappings and settings.
  4. Use Create [OSC] track or rename an existing sequencer track so its name begins with [OSC].

Use the tool

Tracker events

Enter mapping IDs and hexadecimal values directly in effect columns.

Mappings

Define OSC addresses, value conversion, fixed arguments, and destinations.

Automation

Use Renoise automation envelopes as continuous OSC control signals.

Export and Blender

Write a deterministic score and import it through OSC Score Bridge.
