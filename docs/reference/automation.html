Automation

The tool recognizes automation whose destination device has a display name in the form [OSC ID].

Create an automation lane

  1. Create mapping 10, usually in unipolar, bipolar, integer, or range mode.
  2. On an [OSC] track, add an automatable native device. A Gainer or a Meta device works.
  3. Rename the device to [OSC 10].
  4. Disable or leave the proxy device disconnected if it should not affect audio.
  5. Create an automation envelope for one of its parameters and draw the curve.

The particular parameter name is irrelevant. Its normalized envelope value is passed through mapping 10.

Sampling

The setting Automation rate controls how often the envelope is evaluated. The default is 60 Hz. Point envelopes hold their previous value; line and curve envelopes are currently evaluated with linear interpolation between their stored points.

Renoise exposes curve points and play mode but not the audio engine's evaluated curve. The exported 60 Hz samples are deterministic and sufficiently dense for Blender animation, but Renoise's curved scaling is approximated linearly.
