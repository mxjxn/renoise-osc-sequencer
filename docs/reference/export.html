Reference

Export and Blender

Export reads the Renoise song sequence directly. Playback does not need to be running.

  1. Stop playback and save the song.
  2. Choose Tools → Generant OSC → Export Blender score.
  3. Save the .json file.
  4. In Blender, open OSC Bridge → Generant Cues.
  5. Choose Import / bake Generant OSC score and select the exported file.

Only mappings whose destination is blender are written into the score. Generant mappings are intended for live playback control.

Score timing

Effect-column events occur at the start of their Renoise line. Trigger releases use milliseconds. Automation is sampled at the selected rate. Song duration is calculated from the sequence's pattern lengths, the current BPM, and the current LPB.

Pattern commands that change BPM or LPB during the arrangement are not folded into score timing yet. Use constant transport timing for deterministic exports.

Result in Blender

OSC Score Bridge creates or updates Rack OSC Score. An address such as /visual/kick becomes the custom property ["osc:/visual/kick"]. Use that property in a driver for light power, transforms, shader values, modifiers, or Geometry Nodes inputs.
